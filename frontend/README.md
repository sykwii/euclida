# Core UI Release 1 — Iteration 7

Frontend-only patch.

## Что изменено

- Карта больше не показывает исторические ромбы выполненных задач по умолчанию.
- Слой `Історія роботи` вынесен отдельно и включается вручную.
- Для слоя истории добавлен период: `сьогодні / 7 днів / усе`.
- ВП получили ненавязчивые подписи на карте: короткий формат подразделения + название ВП.
- Подписи ВП адаптируются к масштабу:
  - крупный zoom — полная подпись;
  - средний zoom — только короткий номер;
  - малый zoom — подпись скрыта.
- Центр событий больше не показывает весь шум одним списком.
- Добавлены режимы событий: `Важливі / Сьогодні / Усі`.
- Счётчик закрытой панели показывает только важные события, а не весь журнал.
